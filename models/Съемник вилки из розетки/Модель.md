# Съёмник вилки из розетки (Schuko CEE 7/3 / CEE 7/4)

Состояние: обе детали построены. Печатаются в одной плоскости, рычаг печатается
сразу надетым на цапфы (сборки нет).

## Файлы

| Файл | Что это |
|---|---|
| `Съемник вилки.FCStd` | документ FreeCAD: таблица «Параметры», тела «Держатель вилки», «Рычаг» |
| `build.py` | идемпотентный пересборщик: пересоздаёт таблицу и оба тела, все размеры берёт из таблицы |
| `examples/` | исходные фото-референсы |

Пересборка:

```python
exec(open(r"...\Съемник вилки из розетки\build.py", encoding="utf-8").read())
```

Скрипт удаляет все тела, кроме таблицы, и строит заново. Алиасы таблицы
пересоздаются целиком — старые значения не «залипают».

## Порядок построения

Держатель:
1. диск Ø70 × 5;
2. отверстие Ø38 насквозь;
3. два зубца внутрь от кромки отверстия (3 × 2 вылет × 2 высота) на ±90°, только z = 0…2;
4. две цапфы Ø4.5 по бокам (3 и 9 часов), ось на верхнем крае (z = 5), концы x = ±42.5.

Рычаг:
1. кольцо Ø72 / Ø88.8 × 5 — в плоскости диска;
2. ручка 40 × 30 — продолжение обода вверх (тот же слой);
3. ступицы Ø10 × 10 по бокам, центры x = ±41, ось z = 5;
4. отверстия ступиц Ø5.4 — надеваются на цапфы.

## Проверка (базовая линия)

| Что | Значение |
|---|---|
| держатель, объём | 13 866 мм³ |
| держатель, `isValid` / `check` | True / None |
| держатель, габарит | 85 × 70 × 7.25 |
| рычаг, объём | 17 377 мм³ |
| рычаг, `isValid` / `check` | True / None |
| рычаг, габарит | 92 × 118.8 × 10 |
| пересечение держатель ∩ рычаг | 0.0000 мм³ |
| минимальный зазор | 0.45 мм (= `print_clearance`) |

Пробы `isInside`:
- центр отверстия и кольцо вокруг него: пусто / материал — ок;
- зубец (r = 17.2, z = 1) — материал; над ним (z = 3) — пусто; по оси Y (r = 17.2) — пусто (зубцы только на ±90°);
- цапфы x = ±41.5 — материал; над цапфой — пусто.

Поворот рычага вокруг цапф (ось X на z = 5): 0…20° без пересечений с диском.
При 10° ручка поднимается ~13 мм, низ кольца уходит вниз — инструмент поднимается вместе с вилкой.

## Печать

- обе детали плашмя, в одной плоскости; поддержки не нужны;
- рычаг печатается сразу надетым на цапфы (зазор 0.45);
- материал PETG.

## Открытые вопросы

1. **Шейка вилки за буртиком должна быть < Ø34** — иначе диск не наденется
   (правится `tooth_depth`).
2. Зубцы на ±90° должны попадать в салазки заземления розетки — проверить на месте.
3. Размеры ручки (40 × 30) и обода (8.4) — на согласовании.

## Отклонённые варианты (не повторять)

- **Ось через центр (3 и 9 часов) + рычаг-кольцо НАД диском**: ход ~1° (рычаг
  упирается в диск), плюс пластину над пустотой нельзя напечатать без поддержек.
- **Рычаг в одной плоскости с диском и ось через центр**: при повороте идёт ниже
  плоскости — упирается в стол/розетку.
- **Боковые вводы-шлицы в диске**: не нужны, диск надевается по корпусу вилки
  со стороны кабеля и упирается в буртик.
- **Зубцы «наружу»** (пазы в кромке отверстия): отклонено — нужны внутрь.
