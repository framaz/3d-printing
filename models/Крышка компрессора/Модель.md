# Крышка компрессора — рабочие заметки по модели

Документ FreeCAD: `Крышка_компрессора`, файл `Крышка_компрессора.FCStd`; его можно
пересобрать с нуля скриптом `build.py` (лист `Parameters` + геометрия).
Исходники: `Исходные/*.jpg` — Сбоку, Сверху, Сверху-спереди, Снизу, Спереди.

## Деталь

Формованная крышка из листа 1.2 мм: плоская D-образная пластина со срезом по прямой
кромке, выштамповка (бугор) у этой кромки и 4 крепёжных отверстия.

## Принятая трактовка формы (после 4 итераций)

- **Контур**: круг Ø`plate_diameter` со срезом по прямой. Срез на
  `plate_flat_offset_from_right` = 51.6 мм от правого края → от центра
  `plate_flat_offset` = 21.85 мм. Углы среза скруглены `plate_corner_radius` = 0.5.
- **Бугор** = пересечение двух тел, а не одно выдавливание:
  1. дуга **вдоль** кромки — полуэллипс в плоскости YZ: размах `boss_length` = 27,
     высота `boss_rise` = 6.4;
  2. трапеция **поперёк** кромки — XZ: со стороны кромки стенка вертикальная на всю
     высоту, к центру пластины наискось; низ `boss_width_bottom` = 21.8,
     верх `boss_width_top` = 17, высота та же `boss_rise`.
- **Бугор полый**: внутренний контур = внешний, смещённый на `plate_thickness` = 1.2.
  Полость открыта у прямой кромки (устья нет — видно внутрь U) и открыта снизу
  через нижнюю плоскость пластины. Закрыта только с внутреннего торца, стенка 1.2.
- **Отверстия**: 4 × Ø2.7, между центрами 36.2 × 39.4 (в форме `hole_pitch_x/y` заданы
  по ближайшим краям), рисунок соосен центру пластины, без фасок.

### Производные (формулы)

| Ячейка | Переменная | Формула | Значение |
| --- | --- | --- | --- |
| B21 | `plate_radius` | `=plate_diameter / 2` | 29.75 |
| B22 | `plate_flat_offset` | `=plate_radius - plate_flat_offset_from_right` | −21.85 |
| B23 | `boss_rise` | `=boss_height - plate_thickness` | 6.4 |
| B24 | `boss_taper` | `=boss_width_bottom - boss_width_top` | 4.8 |
| B25 | `hole_pitch_cc_x` | `=hole_pitch_x + hole_diameter` | 36.2 |
| B26 | `hole_pitch_cc_y` | `=hole_pitch_y + hole_diameter` | 39.4 |
| B27 | `hole_x` | `=hole_pitch_cc_x / 2` | 18.1 |
| B28 | `hole_y` | `=hole_pitch_cc_y / 2` | 19.7 |
| B29 | `plate_chord_half` | `=sqrt(plate_radius^2 - plate_flat_offset^2)` | 20.19 |
| B30 | `cavity_length` | `=boss_width_bottom - plate_thickness` | 20.6 |

`cavity_length` менялась дважды по мере смены трактовки (была `boss_length - 2*t`,
потом `boss_length - t`). Если снова поменяется топология (закрыть/открыть устье) —
пересчитать её первой.

## Порядок сборки (`build.py`)

1. Пластина: цилиндр R × t ∩ полупространство x ≥ `plate_flat_offset`;
   скругление `plate_corner_radius` на двух вертикальных рёбрах среза.
2. `A` — полуэллипс в YZ (полуоси `boss_length/2` и `boss_rise`), выдавлен по X
   на `boss_width_bottom` от плоскости кромки.
3. `B` — трапеция в XZ (вертикаль у кромки, скос к центру), выдавлена по Y
   на `boss_length`.
4. `boss = A ∩ B`.
5. `solid = plate ∪ boss`.
6. `cavity = A_внутр ∩ B_внутр`, где внутренние контуры смещены на `plate_thickness`;
   `A_внутр` начинается на `plate_thickness` **до** кромки — иначе устье остаётся
   закрытым тонкой гранью.
7. Минус 4 отверстия, `removeSplitter()`, `obj.Shape = solid.Solids[0]`.

## Открытые вопросы

1. **Вершина бугра — гребень** (линия), а не площадка: из-за скругления вдоль кромки
   плоскость z = 7.6 касается свода только по линии y = 0. Если нужна плоская
   площадка, требуется её ширина **вдоль кромки** (мм) — этого числа пока нет.
2. `boss_end_radius` и `boss_base_fillet` (0.5) сейчас не участвуют: скругление даёт
   сама дуга, галтель основания не нужна (стенка у кромки вертикальна). Вернуть
   в профиль, если появятся требования к скруглению торцов/основания.
3. Пластина плоская (`plate_sagitta` = 0) — по фото «Спереди» похоже на выгиб,
   но пользователь подтвердил плоскость.

## Отвергнутые трактовки (не повторять)

1. Трапеция поперёк кромки, выдавленная вдоль кромки → «прямоугольный» бугор.
2. Полуэллипс поперёк кромки (дуга смотрела на пластину) → неверное направление дуги.
3. Полуцилиндр вдоль оси X с устьем у кромки → неверно.
4. Итог: дуга **вдоль** кромки + трапеция **поперёк** = пересечение двух тел;
   именно эта схема даёт одновременно «нет стенки у кромки», «U вдоль кромки»,
   «сверху 17, снизу 21.8, у кромки вертикально, к центру наискось».

## Как дорабатывать

- Менять числа в `Parameters` и запускать `build.py` (скрипт идемпотентен — удаляет
  все объекты, кроме таблицы).
- Форму не пересчитывать выражениями: Part-геометрия выражения не поддерживает,
  пересборка идёт скриптом.
- После пересборки сверяться с эталоном из таблицы выше.
